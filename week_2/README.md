# 复合矩阵中的旋转Rotation、平移Translation、缩放Scale要以怎么有顺序进行
- 对几何体的变换顺序通常为先缩放，后旋转，再平移
- 原因：矩阵乘法并不满足交换律，假设S是一个缩放矩阵，R是一个旋转矩阵，T是一个平移矩阵，SR与RS，RT与TR的变换结果很可能是不同的

# 正交投影和透视投影有什么区别
透视投影产生的图片中的物体会表现为近大远小，而正交投影产生的图片中的物体只与他本身的大小有关，与距离无关

# 简述** 几何体 **变换到屏幕的过程
3D的部分包含了四大变换：世界变换、观察变换、投影变换和视口变换
- 通过世界变换，将物体模型从自身的局部坐标系转换到世界坐标系中
- 引入虚拟摄像机的概念，构建观察空间
- 进行投影变换，将3D的场景投影到一个2D的平面上，包含透视投影和正交投影两种
- 齐次裁剪空间、归一化深度
- 待投影操作完毕后，所有经过透视投影变换后的点[x, y, z, w] 被变换到了齐次裁剪空间
- 进行光栅化
